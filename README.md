
# 💜 KindWords — Compliment & Joke Generator

A fun, interactive, and family-friendly web application that generates quirky compliments and hilarious jokes to brighten your day!

Built entirely with **HTML5, CSS3, and Vanilla JavaScript**, KindWords is a frontend portfolio project focused on delivering a polished user experience, creative design, and interactive functionality without relying on frontend frameworks.

## ✨ Features

### 💬 Compliment Generator
- 100 unique, quirky, and funny compliments.
- Five compliment categories:
  - 🚀 Motivational
  - 😂 Funny
  - ❤️ Romantic
  - 🤝 Friendly
  - 💼 Professional
- Random generation with anti-repetition logic.

### 😂 Joke Generator
- 50 family-friendly jokes.
- Random joke selection.
- Animated punchline reveal after a short delay.
- Fun and engaging interactions.

### 🃏 Playing Card Design
- Playing-card-inspired interface with a 5:7 aspect ratio.
- Two decorative circular icons positioned in opposite corners.
- Matching emojis on both corners of each generated card.
- Randomized emojis and colorful backgrounds.
- Smooth transitions and playful animations.

### ❤️ Favorites & History
- Save favorite compliments and jokes.
- Persistent favorites using browser LocalStorage.
- View recently generated content.
- Easily revisit previously generated compliments and jokes.

### 🎨 Modern UI/UX
- Warm Minimalism design philosophy.
- Light and dark mode.
- Responsive layout for mobile, tablet, and desktop.
- Animated visual effects and colorful backgrounds.
- Custom favicon.
- Accessible controls and keyboard navigation.

### 📤 Sharing Features
- Copy compliments and jokes to the clipboard.
- Share content using supported browser features.
- Interactive feedback messages.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Edge, Firefox, or Safari).
- Visual Studio Code (optional).
- No additional dependencies or installations.

### Installation

1. Download or clone the repository.
2. Open the `compliment-generator` folder.
3. Double-click `index.html`.
4. Start generating compliments and jokes!

Alternatively, open the project in Visual Studio Code and use a local development server such as the Live Server extension.

## 🎮 How to Use

1. Open the application in your browser.
2. Select a compliment category.
3. Click **New Compliment** to generate a random compliment.
4. Click **Tell Me a Joke** to generate a family-friendly joke.
5. Watch the animated punchline reveal.
6. Save your favorite content using the heart icon.
7. Copy or share your favorite compliments and jokes.
8. Switch between light and dark themes.

## 🧪 Testing

The application can be tested locally without a backend.

Recommended tests:

- Generate multiple compliments across all categories.
- Verify compliments do not repeat within a selection cycle.
- Generate jokes and check animated punchlines.
- Save and remove favorites.
- Refresh the page and verify favorites persist.
- Test light and dark mode.
- Test keyboard navigation.
- Check mobile responsiveness.
- Verify the favicon displays correctly.

**Note:** Native sharing and clipboard functionality may depend on browser support and security permissions. Google Fonts requires an internet connection.

## 🌐 Deployment

KindWords can be deployed using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository settings.
3. Navigate to **Pages**.
4. Select **Deploy from a branch**.
5. Choose the main branch and root folder.
6. Save the configuration.

Once deployed, GitHub will provide a public URL for the application.
